# SimulaPRONAF API

Backend de uma aplicação voltada à simulação de crédito rural para agricultura familiar.

---

## 🚀 Sobre o projeto

Projeto desenvolvido com foco em:

- Simplificar acesso ao crédito rural
- Estruturar regras do PRONAF
- Criar base para produto digital no agro

---

## ⚙️ Stack

- Java + Spring Boot
- Spring Security + JWT
- OAuth Google
- PostgreSQL

---

## 🔐 Autenticação moderna

- Login via Google
- Validação de identidade no backend
- Emissão de JWT próprio
- API stateless

---

## 🧠 Arquitetura

- Separação em camadas
- Código organizado por domínio
- Pronto para escalar

---

## 💡 Diferencial

Projeto une:
- conhecimento técnico (backend moderno)
- conhecimento de negócio (crédito rural)
